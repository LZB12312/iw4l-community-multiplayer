# Community multiplayer

Extract the whole ZIP into a folder you can write to, then open **Multiplayer.exe**. Everyone uses the same package and can host or join. Windows 10/11 x64 is required; no Python or PowerShell 7 installation is needed.

1. **Host Internet** starts your relay, forwards UDP using a compatible UPnP router, and opens an online Rust lobby. Approve the Windows administrator prompt to add a firewall rule for this relay executable and UDP port. The invitation is copied to your clipboard; **Copy invitation** copies it again.
2. **Join Internet**: paste a friend's invitation in the launcher and click Join Internet. Select their room in **Find Lobbies**. Join before the host chooses **Start Match**; joining a match already running is not supported.
3. **Play again** uses your saved relay. **Stop my relay** closes all relays belonging to this extracted folder and removes their own router mappings. Closing the launcher leaves the game and relay running so your friends stay connected. A relay started from a different extracted folder must be stopped from that folder.

On first game launch, setup detects MW2 in Steam libraries and lets you select another folder if needed. Each player supplies their own compatible Modern Warfare 2 (2009) multiplayer files, including common_mp and mp_rust. Select your extracted Xbox 360 Skate 3 **default.xex** with its data folder beside it to enable skating. ISO files must be extracted first. Setup converts your own Skate data and prepares the same clothing catalogue automatically. Your game installations are read only; converted data and settings stay in this mod folder. Game files are not included in the ZIP.

Open **Character** in the game to choose a soldier or skater and open **Hall of Meat Settings**. **Edit Skater** opens the original creator when its data is prepared. Your appearance is synchronized with other players while walking and skating. Prepared creator data enables the original Skate menu artwork, fonts, navigation, male/female selection and nose/jaw/mouth/chin sliders; opening it captures gameplay input. Gender changes save before applying and reset to that gender's original default outfit. Left/Right changes selected face sliders by the native adjustment size and saves before applying; continuous analog timing is not yet reproduced. Further wardrobe controls, eyes, brows, body shape, undo, tattoos, preview and menu audio remain in development; unavailable operations are disabled. Older caches use the limited male wardrobe menu for skin, tops, pants, hair and decks. Full profiles also support console editing; `character native default male` or `character native default female` selects an original default. **J** switches modes. XInput controllers use native skating controls; on keyboard, W pushes, A/D steer, S brakes, and holding/releasing Space performs an ollie. MW2 first-person weapon/hand animations remain in use while walking.

Open **Character / Hall of Meat Settings** to adjust the host's damage tolerance. The console commands meat window and meat impulse adjust the accumulation window and impact strength. Accepted MW2 damage keeps normal health, death and respawn; qualifying hits bail active skaters. Physical Hall of Meat events follow the ported Skate 3 ground/air wipeout checks and their extracted game settings. Ordinary contacts do not add launch impulses, and ragdoll contacts cannot repeatedly retrigger the effect. Physical bails do not subtract additional MW2 health. Tolerance 0 disables added combat bails and impact HUD events; Skate's own physics can still bail. The injured player's screen displays the original Skate HUD artwork, fonts and animation. Other players see the animated skeleton inside the selected character's translucent body. Skater bodies clear on respawn and expire after five seconds, including deaths during a mode transition before a skating pose is saved. Scoring, injury tint and body fade currently use mod rules; native fracture rules and the remaining character customization controls remain in development. Older converted folders need the bundled converter's --hall-of-meat-only option before the HUD and skeleton can load.

Matchmaking uses the included encrypted relay independently of Steam services. Each new host generates its own identity locally. Invitations contain public/LAN addresses and the public certificate; the private key stays on the host. Joining checks reachability and the certificate before changing relay settings and preserves your own hosting identity. One group shares the chosen host's relay, and that PC must remain running. Capacity defaults to 18; there is no host migration. Everyone must use this build (protocol 99); protocol98 installations must update together.

## Network setup

UPnP must be enabled on the host's router. The launcher verifies the router mapping, but an outside player must test actual Internet reachability. **Host UDP port** changes both the PC listener and router port, defaults to 4433, and remembers your last successful selection. The host connects locally. New invitations automatically try a matching LAN route first for same-network players, then the public route; both authenticate the same certificate. Older invitations still work, but must be regenerated to include the LAN route.

For manual forwarding, enter **Manual public address** as your-public-address:port and forward that UDP port to the selected **Host UDP port** on the host PC. Joining players do not need to forward ports. Private/shared WAN addresses, double NAT or CGNAT need forwarding through the upstream router, a public IPv4 from the ISP, or a reachable public relay. UPnP cannot make an upstream private connection public; the helper detects this condition. See the [Windows UPnP API](https://learn.microsoft.com/en-us/windows/win32/api/natupnp/nf-natupnp-istaticportmappingcollection-add) and [CGNAT address range](https://www.rfc-editor.org/rfc/rfc6598).

The relay helper removes only its own mapping when the relay exits and restores a lost mapping while it runs. A hard shutdown can leave a static router entry; Host can recover a saved mapping belonging to this folder, or use Stop my relay. If your public IP changes, host again and share the new invitation. Approve the firewall administrator prompt when hosting; setup repairs Windows-generated UDP block rules for this executable before checking connectivity. Joining does not require administrator rights.

## Files and troubleshooting

**Multiplayer.exe** opens the launcher; **Start Multiplayer.bat** is a fallback. Host Internet.bat, Join Internet.bat and Stop Internet Relay.bat remain available. Invitations are saved in matchmaking/Internet Invite.txt; your relay identity stays under matchmaking/. Configuration is saved in .env; character choices in iw4l-character-profile.json (older iw4l-character.txt files import automatically); game and launcher logs in iw4l-artifacts/. Re-extract into a fresh folder if files are missing, then select your game data again.

If audio crackles, open **Audio output** in the launcher and select your actual headphones rather than a virtual surround device, then restart the game. This saves IW4L_AUDIO_DEVICE in .env without changing Windows audio settings. With no selection the game uses the Windows default; an unavailable selected device falls back to that default and records a warning in the game log. Launcher startup errors are saved under iw4l-artifacts/launcher/ and displayed instead of disappearing silently.

Skate board audio uses effects converted from your own Skate 3 copy: rolling, wheel spin, grinds, braking, slides, scrapes, pops, landings, pushes, rattles, seams and body impacts. MW2 collision materials select the closest concrete, asphalt, wood or metal rolling samples; metal landings use the original metal bank. Brief contact gaps are debounced. Nearby multiplayer skaters receive the same surface selection. New conversions include sounds automatically. To upgrade an existing converted folder, run `skate/iw4l-skate-convert.exe --xex "path/to/default.xex" --out "path/to/skate-data" --audio-only`, then restart the game. The decoder is bundled; no extra program is needed. Audio timing and unsupported surface families remain adapted; the full original audio graph is not reproduced.

**Update mod** checks the public GitHub releases and downloads a newer compatible package without GitHub sign-in. Close the game and use **Stop my relay** before installing; close any additional launcher windows too. The updater verifies GitHub's archive SHA-256 and every packaged file, backs up changed files, closes and updates this launcher, then reopens it. Your .env, audio settings, character choices, certificates and converted game data stay local. Failed installations roll back; interrupted updates block game launch until recovery. Run `powershell -ExecutionPolicy Bypass -File Update-Multiplayer.ps1 -Mode Recover` from the mod folder to recover. Headless checks use `-Mode Check`; `-ArchivePath` installs a newer local release ZIP. Private forks can use `-Mode Authenticate` to save a read-only GitHub token encrypted for their Windows account. See the [GitHub release download API](https://docs.github.com/en/rest/releases/assets#get-a-release-asset).

If connection fails, the host should run Host Internet, approve firewall setup, and keep the relay running. Check that both users run this ZIP and the invitation is current. An authenticated relay connection proves transport access; friends still need to join the lobby before the match starts. Manual configuration is available through Configure-Relay.ps1 using a reachable relay address and its public CA.

Failed Skate preparation stops repeated map rebuilds; after fixing the conversion, J requests another attempt. MW2 can still load when required Skate files are missing.

For an older converted Skate folder without clothing, run the bundled converter once with: skate/iw4l-skate-convert.exe --xex "path/to/default.xex" --out "path/to/skate-data" --wardrobe-only. It uses the same deterministic catalogue as first launch. No engine checkout or Python installation is needed.

Share the clean **IW4L-Community-Multiplayer.zip** with friends. Keep the original ZIP for sharing; an installed folder gains your game assets, invitations and private key, which must stay local. The archive includes the game, relay, launcher, standalone asset/wardrobe converter, Windows runtime DLLs, component licenses and corresponding source in runtime-source.zip and skate/converter-source.zip. It includes no game content or host identity. BUILD.json records file hashes. Converter source is based on [SK8-ENGINE/skate-3-rust-engine](https://github.com/SK8-ENGINE/skate-3-rust-engine/tree/4488651c35c44365faa1ba38eed5758b6ebde714); its license and corresponding source are included under skate/.
